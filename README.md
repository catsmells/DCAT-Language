# DCAT-Language
The DCAT scripting language for the DCAT electronic music suite.

## Overview
The DCAT music suite encompasses synthesizers, routers, CDJ software, mixers, and more. I made this scripting language to be used across all DCAT systems for one to more-easily create music, even on an unfamiliar instrument.

Related repository: https://github.com/catsmells/DCAT-101-Scripts
